# eBay Laptop Helper

Chrome-розширення для перегляду ноутбуків на eBay. Версія **1.10.0**.

## Можливості

- Орієнтовна повна ціна у гривнях: `((USD + доставка) × (1 + націнка / 100) + витрати USD) × курс`.
- Кольори назв і цін за верхньою межею повної ціни; власні кольори назв.
- Пошук моделі й процесора на OLX та проданих аналогів на eBay (**SOLD**) з комплектацією.
- Бажані слова підкреслюються; картки з небажаними словами приглушуються.
- На сторінці товару: ціна, доставка, кнопки пошуку, факти й повний опис продавця, порівняння RAM/SSD/CPU/GPU між назвою, характеристиками eBay та описом.
- Переклад витягнутих фактів англійською → українською через локальний перекладач Chrome; повернення оригіналу.
- Редагування пошукового запиту й підготовка питань продавцю англійською для копіювання.
- Головний перемикач, три перемикачі основних функцій, імпорт/експорт налаштувань.

У 1.10 видалено мітки нових товарів, попередження за ризиковими словами й історію спостережень зі змінами цін. Зміни докладно описано в [UPDATE-1.10.md](UPDATE-1.10.md), перевірку — в [AUDIT-2026-10-04.md](AUDIT-2026-10-04.md). Файли змін попередніх версій є історичними.

## Встановлення та оновлення

1. Відкрийте `chrome://extensions` і ввімкніть режим розробника.
2. Натисніть **Завантажити розпаковане розширення** й виберіть папку з `manifest.json`.
3. Для вже встановленого розширення оновіть файли в тій самій папці, натисніть кнопку перезавантаження на картці **eBay Laptop Helper** й оновіть вкладку eBay.
4. Перевірте, що на картці розширення показано **1.10.0**.

Приклад каталогу: [PC Laptops & Netbooks](https://www.ebay.com/b/PC-Laptops-Netbooks/177/bn_317584?LH_BIN=1&rt=nc&_dmd=2&_sop=10).

У меню курс, націнка й витрати розташовані зверху. Додаткові кольори, слова й перенесення налаштувань згруповані у згорнутих розділах. Кнопка **Зберегти** доступна під час прокручування. Головний перемикач застосовується одразу; інші зміни — після збереження. Скидання типових значень зберігає поточний стан головного перемикача.

## Розрахунок і опис

- Перераховуються лише USD. Числові метадані без оголошеної валюти USD не перераховуються.
- Для діапазону цін показуються обидві межі; колір відповідає верхній.
- Враховується доставка, яку показує eBay для вибраної адреси. Якщо її не знайдено, використовується `$0` з поясненням. Це оцінка, а не підтверджена вартість доставки.
- Розширення не змінює адресу доставки й не розраховує митні платежі автоматично; закладіть потрібні витрати в налаштування.
- Опис читається зі сторінки або з фрейму `ebaydesc.com`. Якщо він ще не завантажений, панель пропонує прокрутити до опису продавця.
- Факти витягуються за текстовими правилами, тому повний оригінальний опис залишається доступним. Порівняння характеристик і перелік питань не замінюють перевірки фотографій та комплектації.
- Перекладач запускається лише за натисканням. Chrome може завантажити мовний пакет; якщо API чи мовна пара недоступні, зберігається оригінал і показується пояснення.
- Питання продавцю лише готуються як текст. Розширення їх не надсилає.

## Навантаження й доступ

Розширення використовує лише дозвіл `storage`, працює на eBay та в описах `ebaydesc.com`, не має фонової служби й не записує історію переглянутих товарів. У неактивних вкладках і після вимкнення спостереження за сторінкою зупиняється. Після повернення вкладки її дані перевіряються заново.

Зміна однієї картки обробляє цю картку; додавання нового списку викликає повне сканування до 600 карток. Зміни шапки й сторонніх ділянок не запускають обхід каталогу. Переклад потребує додаткових ресурсів тільки за запитом.

## Перевірка для розробника

Обчислення, правила вилучення даних, налаштування й перекладач:

```sh
node --test tests/*.test.js
```

Браузерні перевірки потребують Playwright та Chrome/Chromium. За потреби задайте `PLAYWRIGHT_MODULE` і `CHROME_EXECUTABLE`:

```sh
node tests/functionality.browser.cjs
node tests/frame-navigation.browser.cjs
node tests/performance.browser.cjs
```

Тести використовують тимчасовий профіль і локальні сторінки, не профіль користувача. Функціональні тести також створюють знімки в `../audit-artifacts/`; інший шлях можна передати через `AUDIT_ARTIFACTS`. Вимірювання навантаження приймає шлях до іншої версії першим аргументом.
